# physics_engine_with_AI

# 인공지능 삽입형 물리 솔버  

## 프로젝트 개요  
본 프로젝트의 주제는 **AI를 통한 물리 솔버의 계산 과정 및 결과 보강**이다.  
강체 물리 엔진 내부의 솔버에 학습 가능한 인공지능을 삽입하여 충돌 계산을 보정하고, 물체 움직임의 정확도를 높이는 방법을 연구한다. 특히 고속으로 이동하는 물체의 계산에서 발생 할 수 있는 오류의 해결 및 정확도 향상, 그리고 계산 과정의 비용을 줄이는 것에 집중한다.  

## 개발 배경
기획서 문제 정의 바탕으로 쓰기

## 주요 목표
이놈은 문제 정의 + 극복 방안으로 작성하면 될듯.
